# Nitroito's Tooltips

A minecraft mod that improves the information displayed on tooltips. Fully customizable via ClothConfig. 

## Features
- Enchantments with difterent colors in order to reflect Rarity and Levels
- Armor Trims with icon for the template as also material
- Banner patterns with icon for the pattern and color for each layer
- BeeNest/Beehive bees and honey information using icons
- Bucket of Entity with full entity info as also a model preview
- Show item durability using values or a gradient progress bar
- Food nutrition, saturation and effects, including attribute modifiers
- Maps with preview, ID, scale, dimension and coordinates
- Painting with preview, size and author
- Potions and Tipped arrows with attribute modifiers
